# Clinical SAS Programming: CDISC SDTM/ADaM & Safety Reporting

## 📌 Project Overview
This project demonstrates an end-to-end Clinical SAS Programming workflow following CDISC standards (SDTM & ADaM). The objective is to process raw clinical trial data, build analysis datasets, perform data validation, and generate standardized clinical summary tables.

## 🛠️ Tech Stack & SAS Procedures
- *Environment:* SAS OnDemand for Academics (ODA)
- *Data Standards:* CDISC SDTM (DM, AE) & ADaM (ADSL, ADAE)
- *SAS Procedures:* PROC REPORT, PROC SQL, PROC FREQ, PROC UNIVARIATE, PROC SORT

## 📊 Key Deliverables & Reports
1. *ADaM ADSL & ADAE Datasets:* Derived age groupings (AGEGR1), treatment-emergent flags (TRTEMFL), and safety population markers (SAFFL).
2. *Table 14.1.1 (Demographics):* Demographic & Baseline Characteristics report using PROC REPORT.
3. *Table 14.3.1 (Safety):* Treatment-Emergent Adverse Events (TEAE) incidence rate summary generated via PROC SQL & PROC REPORT.
4. *Data Quality Checks:* Age distribution analysis (PROC UNIVARIATE) and cross-tabulation (PROC FREQ).
